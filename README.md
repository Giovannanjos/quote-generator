O **Quote Generator** é um script em Python que gera citações inspiradoras direto no terminal. 

Criei o projeto para praticar consumo de APIs RESTful e tratamento de erros de conexão:
- **Modo Online:** Puxa frases em tempo real da API pública DummyJSON.
- **Modo Offline:** Se a internet cair ou a API falhar, ele carrega automaticamente as frases salvas no `quotes.json`.

---

## 🛠️ Tecnologias
- **Python 3**
- **Requests** (para chamadas HTTP)
- **JSON** (armazenamento e leitura local)
